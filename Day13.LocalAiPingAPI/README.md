###
Objectives

The goal of this project is to build a modern Local AI Integration API using ASP.NET Core, Microsoft.Extensions.AI and OllamaSharp while following Clean architecture and SOLID principles.

This project focusses on 

* Local LLM integration
* Microsoft.Extensions.AI Abstractions
* OllamaSharp Integrations
* Ai Service Boundaries
* Ai Provider Abstration
* Minimal light weight API Architecture as MS recommendations.
* Structured Ai Responses
* Metadata Aware Responses
* Dependency injection
* Service Layer Architecture 
* Async Streaming Concepts
* Modern Ai Engineering Habits
* Ai infrastructure thinking
* Clean Backend discipline
