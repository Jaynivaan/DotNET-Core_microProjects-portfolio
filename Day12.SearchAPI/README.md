### Day12.SearchAPI ( .Net Core + Sql server)

### Objectives

The goal of this project is to build a modern Hybrid Search API using ASP.NET Core, SQL Server and EF Core While following clean Architecture and S.O.L.I.D Principles.


This project focuses on : 

- Hybrid Retrieval Systems
- Keyword Search
- Metadata aware Retrieval
- Ranking Logic
- SQL Server Integration
- E F Core Architecture
- Structured API Responses
- Dependency Injection
- Service Layer Architecture
- Modern SEARCH Engineering Habits
- AI-Era retrieval thinking

### Modern Engineering Direction 

This project intentionally avoids outdated backend search patterns.
 
ie,

- tight coupling
- congested program.cs
- raw sql within endpoints
- uncontrolled retrieval 
- direct entity exposure
- chaotic running logic
- hardcoded search scoring

modern methodologies added are
+ Minimal api 
+ EF Core DbContext
+ Sql Server Integration
+ DI
+ Service Layers
+ DTOs
+ Metadata aware response design
+ Config driven ranking behavior
+ Async await system
+ SOLID principles
+ Retrival isolation discipline
