### Day19.ContractOpenAPI

### Objectives

The goal of this project is to understand how modern  APIs  communicate their capabilities  
to other systems through OpenAPI contracts.

The project focuses on :

- OpenAPI Fundamentals
- Api Contract Thinking
- Minimal thin api
- Endpoint discovery..
- Machine readable documentation
- Dto design
- Endpoint Metadata
- API self description
- System integration thinking
- dx

an api has two parts 
1; functionality
2. contract describing the functionality


This project demonstrates how API s expose their contract ina way
developers, frontendapps,  mobileapps, sdk generators, Ai agents 
or any such popularly standardized internet entities can 
discover and understand the API AUTOMATICALLY.
