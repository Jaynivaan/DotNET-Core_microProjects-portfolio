## Day17.SentimentMoodClassifier (.Net Core + ML .Net)

### vision

This project explores how machine learning systems 
begin observing patterns hidden inside language snippets.
instead of manually writing rules like: 

if  text contains "good" => its positive.

that will only make another biased humman being..lol 

let the system learns patterns from examples.

the real vision of this project is not merely sentiment analysis.

the deeper intention is to understand:

how software can be wired to gradually learn statistical behaviour 
by analysing the patterns of data it is exposed to.

eg: 

"I love this product " => positive
"that system is terrible " => negative

model is not manually told every rule ..instead  it takes examples and learn.



### Objectives

The goal of this project is to build a tiny MachineLearning Pipeline using ML.NET 
while understanding how modern ML systems transforms raw data into  predictions.
