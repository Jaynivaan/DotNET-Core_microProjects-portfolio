# Day 04 - File Upload API

---

## Objectives

The goal of this project is to build a simple file upload API using  ASP.NET Core.
to handle file uploads and store them on the server.

----

## Planned Features

-- Upload a file
-- Save uploaded file to local folder
-- Return structured response after upload.
-- Validate if file exists
-- prevent empty file upload.
-- List Uploaded files

-- Use Http endpoints.

-- Return structured responses

### How to run the project

1. Clone the repository to your local machine.

2. Navigate to the project directory in your terminal.
```cd Day04-FileUploadAPI
```
3. Build the project using the following command:
```dotnet build
```
4. Run the project using the following command:
